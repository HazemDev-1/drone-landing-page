# DJI Mavic 4 Pro - Product Landing Page

A nine-section product landing page for the DJI Mavic 4 Pro drone, built from a design reference.

**Stack:** HTML5, CSS3

**Live demo:** https://hazemdev-1.github.io/drone-landing-page/

## Features

- Layout built with CSS floats and clearfix (the assignment focused on classic layout techniques)
- Hero, features, specs, gallery and footer sections
- Consistent spacing and typography across sections

## Run it

No build step. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Context

Built as Assignment 3 of the Route Academy front-end diploma.
